## Quick Examples

### Share a Code Snippet

Perfect for sharing code quickly with colleagues:

```javascript
// Quick code sharing
const snippet = `
function hello(name) {
  return \`Hello, \${name}!\`;
}
`;

// Share on hibi.is
// Result: https://hibi.is/abc123
```

### Create a Quick Note

Jot down thoughts and share them:

```plaintext
Meeting Notes - 2024-01-15
- Discussed Q1 goals
- Assigned tasks
- Next meeting: 2024-01-22

Share link: https://hibi.is/def456
```

### Shorten a Long URL

Make long URLs manageable:

```plaintext
Original:
https://example.com/very/long/path/to/resource?param1=value1&param2=value2

Shortened:
https://hibi.is/ghi789
```

### Share Documentation

Create and share documentation quickly:

```markdown
# API Quick Reference

## Authentication
Bearer token in Authorization header

## Endpoints
- GET /api/users
- POST /api/users
- DELETE /api/users/:id

Share: https://hibi.is/jkl012
```
